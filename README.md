# Telegram Chat Parser & Archiver

Универсальный набор инструментов для парсинга, сохранения и экспорта переписок Telegram.

Проект содержит два взаимодополняющих решения:
1. **`tg_auto_screenshot.py`** — GUI-автоматизация: покадровые скриншоты чата с автоматической прокруткой, сравнением perceptual hash (pHash), защитой от дубликатов и поддержкой Retina/HiDPI дисплеев.
2. **`telethon_forward.py`** — перенос сообщений через официальный Telegram API (Telethon): нативная пересылка пачками (до 100 сообщений) или чистое копирование текста/медиа, защита от FloodWait, фильтры по датам и возобновление пересылки (resume) по чекпоинту.

# .venv\Scripts\activate   # Windows

## Вариант 1: Экспорт чата через Telethon API (`telethon_forward.py`)

Самый быстрый, надежный и качественный способ выгрузить переписку или перенести историю из одного чата/канала в другой.

### Возможности
- **Защита от бана и FloodWait**: настраиваемая пауза (`--delay`), батчинг и автоматическое ожидание при лимитах Telegram.
- **Высокая скорость (батчинг)**: нативная пересылка пачками до 100 сообщений за один сетевой запрос.
- **Поддержка любых чатов**: каналы, группы, личные чаты, числовые ID (включая супергруппы `-100...`) и `"me"` (Избранное).
- **Возобновление (`--resume`)**: автоматический чекпоинт в файл — если процесс прервался, можно продолжить с того же места без дубликатов.
- **Точные фильтры по дате**: `--from-date` и `--to-date` с оптимизацией раннего выхода (не выкачивает лишние гигабайты сообщений).
- **Режимы пересылки**:
  - Нативная пересылка (`--batch-size 20`) — сохраняет плашку «Переслано от».
  - Копирование контента (`--no-forward`) — публикует текст и файлы от вашего имени.
- **Безопасная конфигурация**: поддержка TOML-конфига и переменных окружения.

### Настройка через TOML (рекомендуется)
Скопируйте пример конфига:
```bash
cp telethon_config.toml.example telethon_config.toml
```
Заполните `telethon_config.toml` (ключи `api_id` и `api_hash` получаются на [my.telegram.org](https://my.telegram.org)):
```toml
api_id = 12345678
api_hash = "abcdef0123456789abcdef0123456789"
source = "@source_chat"
target = "@target_chat"  # или "me" для Избранного
reverse = true           # от старых к новым
delay = 1.0              # пауза между отправками
batch_size = 20          # сообщений в одной пачке
```

### Примеры запуска

```bash
# 1. Предварительный просмотр без отправки сообщений (Dry-run):
python telethon_forward.py --dry-run

# 2. Быстрый перенос из конфига (хронологический порядок):
python telethon_forward.py

# 3. Запуск с параметрами из командной строки:
python telethon_forward.py \
  --api-id 123456 --api-hash abcdef012345 \
  --source @source_channel --target @my_backup \
  --reverse --delay 1.0 --batch-size 20

# 4. Копирование сообщений без плашки «Переслано от» (от своего имени):
python telethon_forward.py --source @source_channel --target @my_backup --no-forward

# 5. Фильтрация по датам (за 2024 год):
python telethon_forward.py --source @source_chat --target @backup --from-date 2024-01-01 --to-date 2024-12-31 --reverse

# 6. Продолжить пересылку после прерывания:
python telethon_forward.py --resume
```

При первом запуске скрипт запросит номер телефона и одноразовый код подтверждения из Telegram для создания локального сессионного файла (`forward_session.session`).

## Вариант 2: Авто-скриншотер окна Telegram (`tg_auto_screenshot.py`)

Позволяет автоматически заскринить весь чат сверху вниз через окно приложения Telegram Desktop (полезно, если нет API-доступа, чат запрещает экспорт или нужны точные копии сообщений с версткой).

### Возможности
- **Retina / HiDPI Display Aware**: корректное масштабирование координат и снимков без смещений на экранах Mac и 4K-мониторах.
- **Умное определение конца чата (pHash)**: сравнивает кадры по perceptual hash и останавливается, когда чат прокручен до конца.
- **Защита от дубликатов**: идентичные кадры при микропрокрутках не сохраняются на диск.
- **Стабильный курсор**: курсор мыши не дергается по экрану и не активирует всплывающие кнопки реакций/сообщений Telegram.
- **Метаданные запуска**: сохраняет `metadata.json` с координатами, параметрами прокрутки и временем выполнения.

### Требования к правам (macOS)
Для управления курсором, горячих клавиш и захвата экрана выдайте Terminal / iTerm (или приложению Python) разрешения:
1. **Системные настройки → Конфиденциальность и безопасность → Доступность (Accessibility)**
2. **Системные настройки → Конфиденциальность и безопасность → Ввод с клавиатуры (Input Monitoring)**
3. **Системные настройки → Конфиденциальность и безопасность → Запись экрана (Screen Recording)**

*После выдачи прав перезапустите терминал.*

### Использование

1. Откройте окно Telegram и прокрутите чат в самое начало (верх).
2. Запустите скрипт:
   ```bash
   python tg_auto_screenshot.py
   ```
3. Управление горячими клавишами:
   - **macOS**:
     - `Cmd+Option+1` — зафиксировать верхний левый угол (наведите курсор на начало области сообщений).
     - `Cmd+Option+2` — зафиксировать нижний правый угол.
     - `Cmd+Option+G` — старт процесса автоскриншотов и прокрутки.
     - `Cmd+Option+Q` — остановить захват.
   - **Windows / Linux**:
     - `Ctrl+Alt+1` / `Ctrl+Alt+2` — углы области.
     - `Ctrl+Alt+G` — старт, `Ctrl+Alt+Q` — стоп.

### Альтернативный режим: управление через терминал (`--stdin-controls`)
Если в системе есть конфликты хоткеев или отсутствуют права на Global Input Monitoring:

```bash
python tg_auto_screenshot.py --stdin-controls
```

Команды в консоли:
- `1` — зафиксировать верхний левый угол по текущему положению мыши;
- `2` — зафиксировать нижний правый угол;
- `r` — проверить статус и координаты выбранной области;
- `g` — старт автоскриншотера;
- `q` — остановка;
- `x` — выход.

### Полезные флаги `tg_auto_screenshot.py`
- `--scroll <px>` — шаг прокрутки (по умолчанию `1000` px).
- `--interval <sec>` — пауза между шагами (по умолчанию `0.6` сек).
- `--settle-time <sec>` — пауза для затухания плавной прокрутки Telegram (по умолчанию `0.15` сек).
- `--hash-threshold <0..2>` — чувствительность сравнения кадров (по умолчанию `1`).
- `--patience <N>` — сколько шагов без изменений считать концом чата (по умолчанию `3`).
- `--out <dir>` — указать свою директорию сохранения.
- `--label <name>` — добавить метку к папке `screenshots/<timestamp>_<label>/`.
- `--self-test` — проверка импортов и зависимостей без реальных действий.

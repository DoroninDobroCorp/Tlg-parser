# Авто-скриншотер длинных чатов Telegram (macOS)

Скрипт автоматически делает серию скриншотов выбранной области окна Telegram и прокручивает вниз до конца чата. Управление — глобальными горячими клавишами.

## Возможности
- Выбор прямоугольной области (ROI) по текущей позиции курсора двумя точками.
- Автопрокрутка и серийные скриншоты в папку `screenshots/<timestamp>`.
- Авто-остановка при достижении конца (по совпадению кадров с учётом pHash).
- Глобальные горячие клавиши: `Ctrl+Alt+1`, `Ctrl+Alt+2`, `Ctrl+Alt+G`, `Ctrl+Alt+Q`.

## Требования и права macOS
- macOS 12+.
- Права в Системных настройках:
  1. Системные настройки → Конфиденциальность и безопасность → Доступность (Accessibility) → Разрешите доступ вашему Terminal/iTerm или приложению Python.
  2. Системные настройки → Конфиденциальность и безопасность → Ввод с клавиатуры (Input Monitoring) → Разрешите доступ вашему Terminal/iTerm или приложению Python.
  3. Системные настройки → Конфиденциальность и безопасность → Запись экрана (Screen Recording) → Разрешите доступ вашему Terminal/iTerm или приложению Python.

После выдачи прав перезапустите Terminal/iTerm и при необходимости заново активируйте venv.

Без этих прав горячие клавиши и снятие скриншотов могут не работать.

## Установка
Рекомендуется использовать виртуальное окружение Python 3.10+.

```bash
# создать окружение (если его ещё нет)
python3 -m venv .venv

# активировать окружение (zsh)
source .venv/bin/activate

# обновить pip и поставить зависимости
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Если возникнут проблемы с `pyautogui` на macOS, убедитесь что установлен `pyobjc` и выдали права, указанные выше.

## Использование
1. Откройте окно Telegram с нужным чатом и прокрутите в самое начало (верх).
2. Запустите скрипт:

```bash
python tg_auto_screenshot.py --log INFO
```

3. Горячие клавиши:
 - Windows/Linux:
   - `Ctrl+Alt+1` — зафиксировать верхний левый угол области (наведите курсор на верхнюю границу списка сообщений).
   - `Ctrl+Alt+2` — зафиксировать нижний правый угол области.
   - `Ctrl+Alt+G` — старт процесса скриншотов + автопрокрутки.
   - `Ctrl+Alt+Q` — остановка.
 - macOS:
   - `Cmd+Option+1` — зафиксировать верхний левый угол области.
   - `Cmd+Option+2` — зафиксировать нижний правый угол области.
   - `Cmd+Option+G` — старт процесса скриншотов + автопрокрутки.
   - `Cmd+Option+Q` — остановка.

По умолчанию скриншоты сохраняются в папку `screenshots/<timestamp>/`, например `screenshots/20250101_123000/`, файлами `frame_00000.png`, `frame_00001.png`, ...
Можно добавить метку запуска: `screenshots/<timestamp>_<label>/` через флаг `--label`. При указании `--out` путь берётся как есть.

### Полезные флаги
- `--out <dir>` — своя папка сохранения.
- `--label <text>` — добавить метку к имени папки: `screenshots/<timestamp>_<label>/` (пробелы → `_`, недопустимые символы отбрасываются). Игнорируется, если задан `--out`.
- `--scroll <px>` — величина прокрутки за шаг (по умолчанию 5600).
- `--interval <sec>` — пауза между шагами (по умолчанию 0.6).
- `--hash-threshold <0..2>` — чувствительность сравнения кадров (по умолчанию 1).
- `--patience <N>` — сколько раз подряд без изменений, чтобы остановиться (по умолчанию 3).

### Режим самопроверки (без действий)
Для проверки, что скрипт устанавливается и запускается без синтаксических ошибок, есть self-test:

```bash
python tg_auto_screenshot.py --self-test --duration 10 --log INFO
```

## Альтернативный режим без глобальных хоткеев
Если глобальные хоткеи не срабатывают (часто из‑за отсутствия прав или конфликтов системных сочетаний), используйте режим управления из терминала:

```bash
python tg_auto_screenshot.py --stdin-controls --log INFO
```

В этом режиме вводите команды в терминал:
- `1` — зафиксировать верхний левый угол (по текущей позиции курсора)
- `2` — зафиксировать нижний правый угол
- `g` — старт
- `q` — стоп
- `x` — выход из программы

В этом режиме зависимости могут не быть установлены полностью — он только проверяет импорт и ждёт указанное время.

## Советы
- Если скрипт «не докручивает», увеличьте `--scroll` или `--interval` (дайте больше времени на подгрузку сообщений).
- Если слишком много похожих кадров — уменьшите `--hash-threshold` или увеличьте `--patience`.
- На ноутбуках с трекпадом чувствительность прокрутки может отличаться — подберите `--scroll`.

## Структура
- `tg_auto_screenshot.py` — основной скрипт.
- `requirements.txt` — зависимости.
- `screenshots/` — будет создана автоматически при запуске, туда сохраняются кадры.

## Альтернатива: пересылка всех сообщений через Telethon
Если вместо скриншотов нужно собрать все сообщения и переслать в отдельный чат/канал, используйте `telethon_forward.py`.

Требуются API-ключи Telegram (создаются на https://my.telegram.org):
- API ID
- API HASH

Примеры запуска:
```bash
# Только показать, что будет переслано (без отправки)
python telethon_forward.py --api-id 123456 --api-hash abcdef0123456789 --source @source_chat --target @target_chat --dry-run --log INFO

# Реальная пересылка (с сохранением автора)
python telethon_forward.py --api-id 123456 --api-hash abcdef0123456789 --source @source_chat --target @target_chat --log INFO

# Копирование контента (без «Переслано от»):
python telethon_forward.py --api-id 123456 --api-hash abcdef0123456789 --source @source_chat --target @target_chat --no-forward --log INFO

# Фильтр по датам и направление от старых к новым
python telethon_forward.py --api-id 123456 --api-hash abcdef0123456789 --source @source_chat --target @target_chat --from-date 2023-01-01 --to-date 2023-12-31 --reverse --log INFO
```

При первом запуске откроется авторизация (код в Telegram). Будет создан `forward_session.session` в текущей папке.
